# movies.csv — 프로젝트용

관심 진로: 미디어, 영화, 문화콘텐츠, 마케팅, 추천 서비스

가공본 9,742행 × 5열. 이 파일은 분석·시각화 전 학생이 전처리하는 자료입니다.

## 원자료 및 준비 기준
GroupLens. MovieLens latest-small (generated 2018-09-26). Harper & Konstan (2015), https://doi.org/10.1145/2827872

https://files.grouplens.org/datasets/movielens/ml-latest-small-README.html

원 영화 9,742편 모두 유지. 교사는 평점 평균·개수만 미리 병합해 다중 파일 병합 부담을 줄임. 평가 없는 영화/미등록 장르/연도 없는 제목 유지.

## 열 설명
| 열 | 뜻·단위 |
|---|---|
| `movieId` | 영화 ID |
| `title` | 연도가 괄호로 포함될 수 있는 제목 |
| `genres` | 전체 장르 목록, | 구분, 미등록 표시 존재 |
| `rating_mean` | 0.5~5점 평균, 평가 없으면 결측 |
| `rating_count` | 평가 수, 평가 없는 영화는 결측 |

## 수업용 가공
전처리 연습을 위해 원자료를 다음과 같이 바꿨습니다.
- 빈칸: `rating_mean` 98개, `rating_count` 97개(한쪽만 비어 있는 행이 있음)
- 있을 수 없던 값(→ 모두 빈칸으로 바꿈): `rating_mean` -1.0 25개, 9.0 24개(평점 범위 0.5~5 밖), `rating_count` -10 48개

**현재 파일에는 결측치(빈칸) 외의 이상값이 없습니다.** 범위 밖 값은 모두 빈칸으로 바꿨으므로 전처리는 `isnull().sum()` → `dropna()`/`fillna()`만으로 끝납니다. 아래 빈칸 개수에 바꾼 값이 더해져 실제 빈칸은 더 많습니다.

평가가 없는 영화 18편은 원자료에서 평균과 평가 수가 모두 결측입니다. 현재 빈칸은 `rating_mean` 116개, `rating_count` 115개입니다.

# astronomy.csv — 프로젝트용

관심 진로: 천문학, 우주과학, 물리, 지구과학, 항공우주

가공본 936행 × 11열. 이 파일은 분석·시각화 전 학생이 전처리하는 자료입니다.

## 원자료 및 준비 기준
HYG Star Database v4.4 (Hipparcos, Yale Bright Star, Gliese 카탈로그를 합친 별 목록, 119,614개). hyg_v44.csv.gz. Retrieved 2026-10-30.

https://codeberg.org/astronexus/hyg · https://github.com/astronexus/HYG-Database

맨눈으로 보이는 별(겉보기 등급 `mag` 6.5 이하)만 골랐습니다. 태양과 거리 정보가 없다는 표시(`dist` 100000 이상)인 별, 분광형이 O·B·A·F·G·K·M으로 시작하지 않는 특수한 별은 뺐습니다. 분광형 첫 글자별로 최대 150개를 고정 난수42로 무작위 추출했고(O형은 30개뿐), 분광형이 빈칸인 별 6개는 모두 넣어 id 순으로 정렬했습니다. 원 37열 중 10열을 원 열 이름 그대로 선택하고 `spectral_class` 열을 하나 더했습니다. `lum`은 소수 넷째 자리까지 반올림했습니다.

## 열 설명
| 열 | 뜻·단위 |
|---|---|
| `id` | HYG 별 번호 |
| `con` | 별자리 3글자 약칭(예: Ori 오리온, UMa 큰곰) |
| `ra` | 적경, 시(0~24), 2000년 기준 |
| `dec` | 적위, 도(-90~90), 2000년 기준 |
| `dist` | 지구에서 별까지의 거리, 파섹(pc). 1pc ≈ 3.262광년 |
| `mag` | 겉보기 등급. 숫자가 작을수록 밝게 보임 |
| `absmag` | 절대 등급. 10pc 거리에서 본 밝기, 숫자가 작을수록 실제로 밝음 |
| `ci` | 색지수(B−V). 작을수록 푸르고 뜨거운 별, 클수록 붉고 차가운 별 |
| `lum` | 광도, 태양을 1로 한 배수 |
| `spect` | 분광형(예: G2V, K5III), 빈칸 존재 |
| `spectral_class` | 분광형의 첫 글자(O·B·A·F·G·K·M, 대략 뜨거운 별부터 차가운 별 순서). `spect`에서 만든 가공 열 |

## 수업용 가공
전처리 연습을 위해 원자료 값을 다음과 같이 비웠습니다(고정 난수42, 서로 다른 행).
- 빈칸: `mag` 5개, `dist` 5개, `lum` 5개, `absmag` 3개

그 밖의 빈칸은 원자료에 원래 없던 값입니다: `spect`·`spectral_class` 각 6개, `ci` 8개. 현재 파일에는 결측치(빈칸) 외의 이상값이 없습니다.

맨눈으로 보이는 별만 모았으므로 실제로 밝은 별(거성 등)이 많이 들어 있습니다. 분광형별 평균 광도를 비교할 때 이 표본의 특성이 결과에 영향을 줄 수 있으며, 분광형별 개수는 실제 별의 구성비가 아닙니다.

# health.csv — 프로젝트용

관심 진로: 보건, 간호, 의학, 의료정보, 공중보건

가공본 303행 × 8열. 이 파일은 분석·시각화 전 학생이 전처리하는 자료입니다.

## 원자료 및 준비 기준
Janosi, A., Steinbrunn, W., Pfisterer, M., & Detrano, R. (1989). Heart Disease. UCI. https://doi.org/10.24432/C52P4X

https://archive.ics.uci.edu/dataset/45/heart+disease

Cleveland 303건의 원 열 이름·범주 코드 보존. ca의 원 결측 기호 ?를 CSV 문자열로 보존. 연령구간은 미리 만들지 않음.

## 열 설명
| 열 | 뜻·단위 |
|---|---|
| `age` | 나이(세) |
| `cp` | 흉통 코드1전형적/2비전형적/3비협심증/4무증상 |
| `trestbps` | 입원시 안정혈압mmHg |
| `chol` | 혈청콜레스테롤mg/dL |
| `thalach` | 검사 최대심박수회/분 |
| `exang` | 운동유발협심증1있음/0없음 |
| `ca` | 주요혈관수0~3, 빈칸은 결측 |
| `num` | 원진단상태코드0~4;0과1~4를 구분하기도함 |

## 수업용 가공
전처리 연습을 위해 원자료를 다음과 같이 바꿨습니다.
- 빈칸: `trestbps` 2개, `chol` 2개, `thalach` 2개
- 있을 수 없던 값(→ 모두 빈칸으로 바꿈): `age` -3 1개, `chol` -100 1개, `thalach` -10 1개

**현재 파일에는 결측치(빈칸) 외의 이상값이 없습니다.** 범위 밖 값은 모두 빈칸으로 바꿨으므로 전처리는 `isnull().sum()` → `dropna()`/`fillna()`만으로 끝납니다. 아래 빈칸 개수에 바꾼 값이 더해져 실제 빈칸은 더 많습니다.

`ca`의 빈칸 4개는 원자료의 결측입니다(원자료의 `?` 표기를 빈칸으로 바꿨습니다). `ca` 열은 이제 숫자형입니다.
